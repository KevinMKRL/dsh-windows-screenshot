# Changelog

## 1.0.1

- Added bilingual documentation: English `README.md` and Simplified Chinese
  `README.zh.md`.
- Added localized plugin detail pages: `docs/DETAIL.md` (English) and
  `docs/DETAIL.zh.md` (Chinese), sharing a text-free feature preview.
- Localized screenshot errors in the client so the chooser follows the active
  DSH language (including the Windows-only and timeout cases).
- The public package remains source-installable from GitHub.

## 1.0.0

- First public release.
- Camera button in the composer's left tool row.
- Area, window, and full-screen capture with a native Windows overlay.
- Delay of 0, 1, 3, 5, or 10 seconds, with countdown and `Esc` cancel.
- Automatic import of the finished PNG into the current composer draft.
- Screenshots saved under `$DSH_HOME/screenshots`.
- DSH window restored to the foreground after capture.
